Этот справочник — для тех, кто сталкивается с указанием кодов специальностей и направлений подготовки в дипломах, приложениях к дипломам, резюме, кадровом учёте, образовательных программах и учётных системах. ## Что кодирует ОКСО

**ОКСО** — общероссийский классификатор, в котором записаны **специальности и направления подготовки по образованию**. Он отвечает на вопрос **«что человек закончил»**.

В текущем снимке справочника содержится **1593 записи**. Классификатор представлен плоским списком (без дерева в интерфейсе). Записи разделены на 9 разделов по уровням образования:

- **I** — профессии СПО (рабочие);
- **II** — специальности СПО (специалисты);
- **III** — бакалавриат;
- **IV** — магистратура;
- **V** — специалитет;
- **VI** — аспирантура;
- **VII** — адъюнктура;
- **VIII** — ординатура;
- **IX** — ассистентура-стажировка.

Каждая карточка содержит:
- **Внутренний код** (например, `I.1.05.01.01`). Римская цифра в начале — раздел (уровень образования), остальное — официальный код.
- **Официальный код** (например, `1.05.01.01`). Показывается в подсказке кнопки кода. Используется в дипломах и приложениях.
- **Наименование** (например, «Гидрометнаблюдатель»).
- **Уровень** (Раздел / Область / Укрупнённая группа / Специальность).
- **Раздел** (I–IX).
- **МСКО 2011** и **МСКО-О 2013** — международные коды образования (только у специальностей).

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду.** Введите `1.05.01.01` (официальный) или `I.1.05.01.01` (внутренний). Поиск строго с начала кода.
- **Поиск по МСКО.** Введите `768` — найдёт все специальности с кодом МСКО 2011 = 768.
- **Поиск по названию.** Одно или несколько слов по логике «И»: `программная инженерия`, `экономика`, `лечебное дело`.
- **Копирование в один клик.** Клик по коду копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Фильтр по разделам.** Выпадающий список рядом с поисковой строкой. Бейдж раздела в карточке тоже кликабельный.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. В текст автоматически подставляются наименование, ссылка, все коды и уровень.
- **Прямые ссылки на коды.** Каждый код можно передать через `?code=…` в адресе — как внутренний, так и официальный.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Как пользоваться

1. **Откройте страницу** — сразу показывается первая порция записей в порядке источника.
2. **Начните вводить запрос** — код, МСКО или слово из названия.
3. **Кликните по коду** в карточке — он скопируется.
4. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
5. **Выберите раздел** в выпадающем списке или кликните на бейдж раздела в карточке, чтобы отфильтровать список.
6. **Нажмите «Очистить»**, чтобы сбросить запрос и фильтр.

> **Важно про код.** В карточке показывается **внутренний код с префиксом раздела** (`I.1.05.01.01`), потому что официальный код `1.05.00.00` встречается в разных разделах с разными детьми. Римская цифра в начале кода однозначно определяет раздел (уровень образования) и делает код уникальным. Официальный код без префикса всегда виден в подсказке кнопки кода.

## Прямые ссылки на коды

Каждый код можно открыть напрямую — например:
- `https://prog815.github.io/okso/?code=I.1.05.01.01` — откроет карточку «Гидрометнаблюдатель» (внутренний код).
- `https://prog815.github.io/okso/?code=1.05.01.01` — то же самое по официальному коду.

Ссылка с `?code=` сразу подставляет код в строку поиска и подсвечивает нужную карточку. Пока идёт deep-link, поиск работает по точному совпадению кода.

# ОКСО — справочник специальностей по образованию

Мгновенный поиск по Общероссийскому классификатору специальностей по образованию (ОК 009-2016). Без регистрации, без установки.

🌐 **Открыть справочник:** [https://prog815.github.io/okso/](https://prog815.github.io/okso/)

---

Коллеги, этот справочник — для тех, кто подбирает коды специальностей и направлений подготовки для дипломов, резюме, кадрового учёта, образовательных программ, учётных систем вроде 1С:Университет, а также для абитуриентов, студентов и выпускников. Главная задача — помочь быстро найти корректный код ОКСО по названию специальности или по самому коду и скопировать его в один клик.

## 🎯 Что это и для кого

**ОКСО** — общероссийский классификатор специальностей по образованию. Он отвечает на вопрос **«что человек закончил»**: код специальности или направления подготовки, по которому выдаётся диплом.

Справочник пригодится, если вам нужно:

- указать код специальности в резюме, дипломе, приложении к диплому и других документах об образовании;
- сверить код в учётной системе (1С:Университет, ERP) со справочником;
- подобрать направление подготовки по названию;
- посмотреть международные коды МСКО для сопоставления с зарубежной системой образования;
- расшифровать код из чужого документа и понять, что за специальность за ним стоит.

## ⚡ Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти».
- **Код в карточке.** Внутренний код ОКСО — `I.1.05.01.01`, где римская цифра в начале — это раздел (уровень образования), а остальные цифры — официальный код специальности. Клик по коду копирует его в буфер, а официальный код (`1.05.01.01`) показан в тултипе кнопки (наведите курсор).
- **Поиск по коду — с начала строки.** Введите `1.05`, `1.05.01.01` или `I.1.05` — справочник найдёт нужную карточку. Код ищется строго с начала, в середине не ищется, чтобы отсечь случайные совпадения.
- **Поиск по наименованию.** Одно или несколько слов по логике «И»: `программная инженерия`, `экономика`, `лечебное дело`.
- **Фильтр по 9 разделам.** Выпадающий список рядом с поисковой строкой; бейдж раздела в карточке тоже кликабельный.
- **Плоский список.** Все 1593 записи выстроены единым списком карточек. Уровень записи (раздел / область / укрупнённая группа / специальность) виден в бейдже карточки.
- **МСКО 2011 / МСКО-О 2013 в карточке.** Для специальностей (уровень 4) отображаются международные коды образования — МСКО 2011 и МСКО-О 2013. Они могут понадобиться при подаче документов в зарубежные учебные заведения или для сравнения систем образования разных стран.
- **Копирование строки.** Кнопка `📋 строка` копирует данные целиком в формате `код; название`.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` отправляет ссылку на конкретную карточку.
- **Прямые ссылки на коды.** Каждый код можно передать через `?code=…` в адресе — как внутренний (`I.1.05.01.01`), так и официальный (`1.05.01.01`).
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## 🧭 Как пользоваться

1. **Откройте страницу** — сразу показывается список записей в порядке источника.
2. **Начните вводить запрос** — код или слово из названия специальности.
3. **Кликните по коду** в карточке — он скопируется в буфер.
4. **Нажмите `📋 строка`**, если нужно скопировать данные целиком в формате `код; название`.
5. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
6. **Выберите раздел** в выпадающем списке или кликните на бейдж раздела в карточке, чтобы отфильтровать список.
7. **Нажмите «Очистить»**, чтобы сбросить запрос и фильтр и вернуться к полному списку.

> **Важно про код.** В карточке показывается **внутренний код с префиксом раздела** (`I.1.05.01.01`), потому что официальный код `1.05.00.00` встречается в разных разделах с разными детьми. Например, «Науки о Земле» (`1.05.00.00`) есть в разделах I, II, III, IV, V, VI, VII — это разные записи с разными наборами вложенных специальностей. Римская цифра в начале кода однозначно определяет раздел (уровень образования) и делает код уникальным. Официальный код без префикса всегда виден в тултипе кнопки кода.

## 🔗 Прямые ссылки на коды

Каждый код можно открыть напрямую:

- `https://prog815.github.io/okso/?code=I.1.05.01.01` — откроет карточку «Гидрометнаблюдатель» (внутренний код).
- `https://prog815.github.io/okso/?code=1.05.01.01` — то же самое по официальному коду.
- `https://prog815.github.io/okso/?code=2.09.03.04` — откроет карточку «Программная инженерия».

Ссылка с `?code=` сразу подставляет код в строку поиска и подсвечивает нужную карточку. Пока идёт deep-link, поиск работает по точному совпадению кода — `?code=1` не вывалит весь раздел I.

## 🆚 Не путать с соседями

Самая частая ошибка — искать в ОКСО виды деятельности, продукцию, занятия или конкретные должности.

| Справочник / источник | Что это | Когда нужен |
|---|---|---|
| **ОКСО** (этот) | Классификатор **специальностей по образованию** | Указание «что человек закончил» |
| **ОКЗ** | Классификатор **занятий** (кто работает) | Указание «кем работает» |
| **ОКПДТР** | Справочник **должностей и профессий рабочих** | Указание «какая конкретная должность» |
| **ОКВЭД2** | Классификатор **видов экономической деятельности** | Указание «чем занимается организация» |
| **ОКПД2** | Классификатор **продукции и услуг** | Указание «что производится или поставляется» |
| **ОКОПФ** | Организационно-правовые формы | Указание формы организации |
| **ИНН / СНИЛС** | Идентификаторы конкретного человека или юрлица | Указание «кто именно» этот человек или фирма |

**ОКСО — это код специальности по диплому, а не код должности, организации или продукции.** Если нужен код должности из штатного расписания — вам нужен ОКПДТР. Если нужен код занятия (кем работает человек) — вам нужен ОКЗ. Если нужен код продукции — ОКПД2.

## ❓ FAQ

**Почему в карточке код вида `I.1.05.01.01`, а в дипломе может быть `1.05.01.01`?**
Внутренний код ОКСО в справочнике имеет префикс раздела (`I.` — раздел I, СПО рабочие). Это нужно потому, что **официальный код неуникален**: `1.05.00.00` («Науки о Земле») встречается в разных разделах с разными детьми. Римская цифра в начале гарантирует уникальность. Официальный код без префикса всегда виден в тултипе кнопки кода — наведите на код в карточке, чтобы увидеть `1.05.01.01`. При поиске можно вводить оба формата.

**Что такое МСКО 2011 и МСКО-О 2013?**
Это международные классификации образования ЮНЕСКО. В ОКСО для каждой специальности указаны два кода: МСКО 2011 (код программы) и МСКО-О 2013 (код области). Они могут понадобиться при подаче документов в зарубежные учебные заведения или для сравнения систем образования разных стран. Коды МСКО есть только у специальностей (уровень 4), у более крупных групп — разделов, областей, групп — их нет.

**Что означают разделы I–IX?**
Это официальные уровни образования в ОК 009-2016: I — профессии СПО (рабочие), II — специальности СПО (специалисты), III — бакалавриат, IV — магистратура, V — специалитет, VI — аспирантура, VII — адъюнктура, VIII — ординатура, IX — ассистентура-стажировка. Раздел определяется официальным кодом специальности: две цифры `ZZ` в `X.YY.ZZ.WW` кодируют раздел.

**Почему в интерфейсе нет дерева иерархии, если в классификаторе 4 уровня?**
Иерархия в ОКСО есть и валидна (раздел → область → укрупнённая группа → специальность). Но в интерфейсе мы показываем плоский список: (1) так удобнее работать с 1593 записями, если нужен один конкретный код; (2) уровень каждой записи виден в бейдже карточки (`4 · Специальность`); (3) официальный код в тултипе позволяет понять место специальности в общей структуре. Если вам нужна именно структура — используйте официальный текст классификатора по ссылкам из блока «Источник и актуальность».

**Чем ОКСО отличается от ОКЗ?**
ОКСО отвечает на вопрос «что человек закончил» (какая у него специальность по диплому). ОКЗ отвечает на вопрос «кем он работает» (какое у него занятие на рабочем месте). Один и тот же человек с дипломом «Экономист» (`5.38.03.01`) может работать и бухгалтером, и финансовым аналитиком, и руководителем — это разные коды ОКЗ.

**Чем ОКСО отличается от ОКПДТР?**
ОКПДТР — справочник конкретных должностей и профессий рабочих («Ведущий инженер-программист», «Слесарь-ремонтник»). ОКСО — справочник специальностей по образованию («Программная инженерия», «Экономика»). ОКСО используется для дипломов и учёта образования, ОКПДТР — для штатного расписания.

**Почему в дипломе код одной длины, а в справочнике — с римской цифрой?**
В дипломе указывается официальный код без префикса (`1.05.01.01`). В справочнике — внутренний код с префиксом (`I.1.05.01.01`), чтобы различать одинаковые официальные коды из разных разделов. Оба формата взаимозаменяемы: `?code=I.1.05.01.01` и `?code=1.05.01.01` открывают одну и ту же карточку. То же работает и в поиске: `1.05.01.01` и `I.1.05.01.01` находят одну и ту же запись.

**Можно ли искать по частичному совпадению кода?**
Поиск по коду работает строго с начала строки. Если вы введёте `1.05`, справочник найдёт группу «Науки о Земле» и все вложенные специальности. Но не найдёт специальность, где `1.05` встречается в середине кода. Искать нужно с начала: `1.05`, `1.05.01`, `1.05.01.01`.

**Можно ли скопировать код одним кликом?**
Да. Нажмите на код (`I.1.05.01.01`) — скопируется только код. Кнопка `📋 строка` скопирует `код; название` одной строкой, например: `I.1.05.01.01; Гидрометнаблюдатель`. При копировании через `📋 строка` или `?code=` всегда используется «чистый» код без лишних символов.

## ⚠️ Ограничения и дисклеймер

- Справочник носит **справочный характер** и не является точной копией официального документа.
- Он **не заменяет** документы об образовании, дипломы и не является реестром дипломов.
- Он **не заменяет** ОКЗ (занятия), ОКПДТР (должности), ОКВЭД2 (виды деятельности), ОКПД2 (продукция), ОКОПФ (формы организаций), ИНН и СНИЛС (идентификаторы).
- Состав и наименования записей воспроизводят редакцию источника без ручных изменений.
- Внутренний код хранится строкой; римский префикс — часть внутреннего идентификатора, официальный код — в тултипе.
- Коды МСКО приведены для каждой специальности по источнику.
- Если вы нашли неточность в данных — сверьтесь с первоисточником (Росстандарт).
